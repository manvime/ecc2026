# Livro ECC 2026

Leitor com 41 folhas, numeração sobre a página e efeito de virada.
Use as setas ou deslize para navegar. Para ampliar, afaste dois dedos sobre a folha.

## Atualizar no GitHub Pages

1. Extraia o pacote e substitua `index.html` na raiz do repositório `manvime/ecc2026`.
2. Se `livro-pdf.enc` estiver no repositório, remova esse arquivo da versão atual.
3. Após publicar, teste no mesmo endereço usado pelo QR code.

O leitor mostra as folhas e não oferece download do PDF. Capturas de tela continuam possíveis.
